# Reproducible results

Generated by `python forecast.py` using the supplied full internship dataset and 200 trees per model. These are historical forecasts after August 20, 2023.

- `data_audit.json`: row exclusions, date range, and assumptions.
- `evaluation_summary.json`: pooled errors for all three forecast methods.
- `backtest_predictions.csv`: 72 recursive validation predictions and baselines.
- `backtest_metrics.csv`: per-series method comparisons.
- `forecasts_4_weeks.csv`: 24 future predictions relative to the dataset end.
- `weekly_sales.csv`: Monday-based company/size time series.
- PNG files: plots shown in the project README and notebook.

Generated customer segments remain local and are not included in the committed snapshot. Re-running the script recreates them.
